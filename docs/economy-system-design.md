## 2. 村民性格系統

### 2.1 性格維度（7 維度 14 種性格）

每個村民在遊戲開始時從 7 個維度中隨機抽 4 個，每個維度抽一個正面或反面性格。

| 維度 | 正面 | 反面 | 影響機制 |
|------|------|------|----------|
| **社交** | 外向 | 內向 | 聊天觸發機率 ×2/×0.5、社交值下降速度 ×1.5/×0.5 |
| **態度** | 友善 | 暴躁 | 聊天後好感度 +2/-1 |
| **信任** | 信任 | 多疑 | 熟悉度提升 ×1.5/×0.7 |
| **感情** | 浪漫 | 矜持 | 異性好感度 ×1.5/×0.7 |
| **勇氣** | 勇敢 | 膽小 | 對陌生人（熟悉度<30）搭話機率 ×2/×0.3 |
| **心態** | 樂觀 | 悲觀 | 心情變化幅度（待實作） |
| **作息** | 早起鳥 | 夜貓子 | 見下表 |

### 2.2 作息性格效果

| 效果 | 時段 | 早起鳥 | 夜貓子 |

| **工作效率** | 白天（6:00-18:00） | +5% | -5% |

## 6. 背包系統

### 6.1 基本規則

- 每個村民有 **5 格**背包空間
- 每格只能放**同一種**物品
- 普通物品最多疊放 **10** 個
- 工具**不可疊放**（每個有獨立耐久度）

### 6.2 背包操作

| 操作 | 說明 |
|------|------|
| 撿起 | 地上物品 → 背包（需有空格或可疊加）|
| 放下 | 背包物品 → 地上（該格需空或同類物品）|
| 使用 | 消耗物品（食物）或消耗耐久度（工具）|
| 交易 | 物品 ↔ 金錢 |

### 6.3 物品擁有權

| 擁有狀態 | 說明 |
|----------|------|
| 有擁有者 | 屬於該村民，只有他能撿起 |
| 無主 | 任何人可撿 |

### 6.4 背包顯示範例

```
王大明的背包：
┌─────┬─────┬─────┬─────┬─────┐
│⛏️75%│🌾 8 │     │     │     │
└─────┴─────┴─────┴─────┴─────┘
金錢：$50
```

## 8. 工具耐久度

### 8.1 耐久度機制

- 每次工作消耗耐久度：**-5**
- 耐久度歸零：**工具直接消失**（從背包移除）
- 沒有工具：無法工作（需先去鐵匠購買）
- 工具不可修理，損壞後需購買新的

### 8.2 職業與工具對應

| 職業 | 需要工具 |
|------|----------|
| 農夫 | 鋤頭 |
| 礦工 | 鶴嘴鋤 |
| 伐木工 | 斧頭 |
| 牧羊人 | 剪刀 |
| 屠夫 | 屠刀 |
| 鐵匠 | 錘子 |
| 木匠 | 鋸子 |
| 皮革匠 | 刮刀 |
| 裁縫 | 剪刀 |
| 磨坊主 | 不需要 |
| 麵包師 | 不需要 |
| 織工 | 不需要 |
| 酒保 | 不需要 |
| 商人 | 不需要 |

### 8.3 工作流程

```
1. 檢查背包是否有工具
   ├─ 沒有 → 前往鐵匠購買 → 返回工作
   └─ 有 → 繼續

2. 執行工作
   ├─ 工具耐久度 -5
   ├─ 產出物品 → 放入背包
   └─ 若耐久度 ≤ 0 → 工具消失（從背包移除）

3. 背包滿了？
   ├─ 滿了 → 物品放在工作地點地上
   └─ 沒滿 → 繼續工作

4. 下次工作前
   └─ 若無工具 → 前往鐵匠購買新工具
```

## 10. 經濟流程

### 10.1 物品存放流程

| 場景 | 物品位置 |
|------|----------|
| 生產中 | 村民背包 |
| 背包滿 | 自己家裡地上 |
| 交易後 | 買家可撿取（地上或轉移） |
| 買完 | 買家背包 |

### 10.2 交易流程

**步驟一：買家找賣家**
- 磨坊主需要穀物
- 檢查磨坊有沒有自己的穀物
- 沒有 → 去找農夫（走到農夫位置）

**步驟二：對話交易**
- 磨坊主：「我需要穀物，賣我 8 個？」
- 農夫：「好，8 個穀物 $16」
- 交易執行：
  - 磨坊主金錢 -$16
  - 農夫金錢 +$16
  - 穀物擁有權改為「磨坊主」

**步驟三：物品交接**
- 情況 A：穀物在農夫背包 → 農夫把穀物丟在地上 → 磨坊主撿起
- 情況 B：穀物在農夫家地上 → 擁有權直接改為磨坊主 → 磨坊主去農夫家撿

### 10.3 金錢流向

```
[L1 生產者] ──賣原料──→ [L2 加工者] ──賣半成品──→ [L3 成品者]
                                                      │
                                                      ▼
                                                  [村民消費]
                                                      │
              ←─────────── 購買工具/商品 ─────────────┘
```

## 11. 規則系統與 AI 分工

### 11.1 設計原則

| 系統 | 負責內容 | 優點 |
|------|----------|------|
| **規則系統** | 做什麼？找誰？買多少？付多少錢？ | 快速、確定性、不花 API 費用 |
| **AI** | 怎麼說？語氣？個性反映？ | 對話自然、有個性 |

**簡單說：規則決定「做什麼」→ AI 決定「怎麼說」**
